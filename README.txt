JA1 Church Presenter — Android Studio project

This is Android SOURCE CODE, not a compiled APK.

To create an APK:
1. Open this folder in Android Studio on a computer.
2. Allow Gradle to sync and install Android SDK 35 if prompted.
3. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Copy app/build/outputs/apk/debug/app-debug.apk to your Huawei MatePad 12 X.
5. Install it after allowing installation from the file manager if prompted.

The app embeds the offline HTML presenter and supports selecting XML/TXT/image files.
Presentation popups are displayed inside the same Android app. Separate HDMI output is NOT guaranteed and depends on Huawei hardware/OS support.
This project has not been compiled or tested on the tablet.
