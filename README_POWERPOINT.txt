STATIC POWERPOINT SLIDES (PDF IMPORT)

The Android APK imports PDF slide decks exported from PowerPoint. PPTX is not directly supported: export/save as PDF in PowerPoint or another office app, then import PDF into Anointed Presenter. This preserves static layout, fonts and images much more faithfully than extracting PPTX text. No animations, embedded videos, or slide notes.

The tablet displays the current slide and next-slide preview, Previous/Next and Blackout. The native Presentation on a separate HDMI display renders only the slide bitmap. Imported PDF is stored privately and reopens after app restarts. Export Library JSON does not include the PDF: retain a copy separately.

Fix: previously the native restore ran before playlists were initialized (JavaScript TDZ); now it runs after playlist declarations. This could have prevented initialization and saving.

Not compiled or tested on the Huawei MatePad. Do not uninstall previous app or clear app data before backing up.
